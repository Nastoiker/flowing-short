# Frontend Flowing Short

Next.js 15 App Router, React 18, RTK Query и Tailwind. Команды запуска всего приложения и отдельного клиентского демо находятся в корневом README.

## Структура

- `app/` — маршруты и композиция страниц; главная страница делегирует ленту feature-модулю.
- `features/video-feed/` — пагинация и состояния ленты, карточка видео, жизненный цикл медиаплеера. `PlaybackProgress` обновляется отдельно от карточки при `timeupdate`.
- `features/auth/` — клиентская сессия; гостям не отправляются защищённые запросы. Формы входа и регистрации заблокированы до hydration.
- `features/discovery/` — каталог авторов, который читает серверную проекцию событий регистрации.
- `stores/` — фабрика Redux store на каждый Provider; RTK Query кеширует запросы. Пустой Redux Saga удалён.
- `components/` — общие элементы и оставшиеся старые страницы. `Layot.video.tsx` и `video/video.tsx` — совместимые адаптеры для старых импортов, новая логика живёт в feature-модуле.
- `e2e/` — Chromium desktop/mobile: реальные сценарии приложения и отдельные регрессии ошибок/пагинации/медиаплеера.

## API и производительность

Главная лента использует `GET /api/Video/feed?limit=12&offset=0&sort=recent|popular`: `{items,hasMore,nextOffset}`. Сортировка применяется на сервере ко всей выборке, новая сортировка сбрасывает страницы; повторная страница обновляет существующие записи без дублей. Старый массив `/api/Video/` сохранён для старых экранов.

Карточка не делает запросы сама при монтировании. Комментарии и причины жалоб загружаются по действию пользователя. Гостевая лента не вызывает `/auth/authByJwt`, `/user/follows` и `/Video/report/reports` — это проверено браузерным тестом. Видео стартует по действию пользователя; переключение карточки, уход за экран, скрытие вкладки и unmount останавливают медиа. Отложенный `play()` защищён от гонки с остановкой.

`GET /api/creators?limit=30` читает каталог авторов. Он может обновиться с небольшой задержкой после регистрации; никакого подключения браузера к Kafka нет.

## Проверки

```sh
npm ci
npm run typecheck
npm run build
# Сначала поднимите и заполните отдельный тестовый Compose из корневого README.
# Bash: export PLAYWRIGHT_BASE_URL=http://127.0.0.1:13000
# PowerShell: $env:PLAYWRIGHT_BASE_URL='http://127.0.0.1:13000'
npm run test:e2e
```

При сбое Playwright сохраняет HTML/JUnit, screenshot, video и trace. Файлы игнорируются Git. Старые административные экраны и редакторы остаются отдельным направлением постепенной миграции; эта работа не объявляет весь frontend переписанным.

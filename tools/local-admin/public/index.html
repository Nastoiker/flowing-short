Как устроен доступ

Панель управления работает только локально. Клиенту отправляйте публичную ссылку Cloudflare из карточки проекта. Компьютер, Docker и туннель должны оставаться включёнными.

«Скрыть ссылку» отключает внешний доступ. «Остановить» также выключает контейнеры проекта — сохранённые данные остаются на диске. При новом запуске публичный адрес может измениться.
